# UI / UX Pro Max

## 何时加载

界面结构、视觉、动效、表单与反馈相关任务；需要把「能用」提升到「清晰、一致、可信」。

## 工作流（按顺序）

1. **目标与用户任务**：主任务一句话；临界路径上最多三个核心操作。
2. **信息优先级**：一屏一个主焦点；次要信息折叠或延后；避免视觉噪声与平等罗列。
3. **布局与层级**：标题/正文/辅助字阶与间距系统化；触摸目标与留白符合常见 HIG/Material 级可读性。
4. **状态完整**：默认 / 加载 / 空 / 错 / 禁用 / 成功；错误给用户**下一步**，不堆栈跟踪术语。
5. **一致性**：同类操作用同类控件；图标与文案与项目既有模式对齐。
6. **动效**：有目的、短、可减弱；不打断阅读；尊重 `prefers-reduced-motion` 类约定（若技术栈支持）。
7. **验收**：桌面 + 窄视口至少其一；键盘路径与焦点可见性（Web）；对比度不依赖唯颜色。

## 输出习惯

- 先结构（大纲/线框级描述）再细节，避免一上来抠像素却无整体。
- 修改 UI 时标注**可观察验收点**（见什么算完成）。

## 深度参考

复杂主题（数据密度、仪表板栅格）可拆任务，结合 `web-design-guidelines`。
