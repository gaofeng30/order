# Prompt Templates for Product Poster Design Director

Use these templates as building blocks. Adapt them to the user's brand, product, language, and channel.

## Template 1: Main generation prompt
```text
请基于我提供的参考图和以下需求，生成一张 [尺寸]、[比例]、[方向] 的专业产品宣传海报，用于 [使用场景]。

【整体目标】
- 海报用途：[电视播放 / 会展现场 / 门店灯箱 / 电商主图 / 社交传播]
- 核心转化目标：[突出价格 / 突出新品 / 突出品牌背书 / 突出菜单信息]
- 主品牌：[品牌名]
- 主推产品：[产品名]
- 主卖点：[主卖点]

【参考图使用方式】
- 参考图1用于学习：[品牌色 / 吉祥物 / 产品包装 / 构图 / 氛围]
- 参考图2用于学习：[产品实物质感 / 包装 / 食欲感 / 材质]
- 不要照搬参考图构图，不要保留无关平台界面元素，不要生成手机截图感。

【版式结构】
- [左侧/上方/中心] 为主视觉区，包含：[品牌名、产品、主卖点、价格、吉祥物、实物图]
- [右侧/下方] 为信息区，包含：[菜单 / 商品清单 / 活动规则 / 门店信息]
- 信息层级：第一眼看到 [核心信息]，第二眼看到 [产品/品牌]，第三眼看到 [辅助信息]。

【主视觉要求】
- 标题：[标题文案]
- 核心价格或利益点：[例如：爆款会展价 4元/根]
- 价格必须足够大、对比强、远距离可读。
- 产品需要有 [食欲感 / 科技感 / 高端感 / 真实质感]。
- 品牌元素需要清晰但不要压过核心卖点。

【信息区要求】
[按用户实际内容写清楚商品、价格、分组、对齐方式]
- 不要使用编号，除非用户明确要求。
- 商品名左对齐，价格右对齐。
- 保持足够行距，适合远距离阅读。

【风格要求】
- 风格：[品牌促销海报 / 电商爆款 / 会展电视广告 / 高级菜单灯箱]
- 色彩：[主色、辅助色、强调色]
- 质感：[立体、清爽、热卖、高端、可信赖]
- 文字要尽量准确、规整、清晰。

【负面约束】
- 不要 [手机UI、平台界面、错别字、乱码、低清晰度、过度拥挤、不准确logo、无关元素]
```

## Template 2: Direction-preserving revision prompt
```text
这版方向正确，不要重新设计，不要换风格。请在当前基础上做局部精修。

请保留：
- [已满意的构图]
- [品牌主色]
- [主视觉元素]
- [核心价格/卖点]
- [信息区结构]

请优化：
1. [主卖点层级，例如价格更醒目，副标题缩小]
2. [品牌区，例如logo更正式，避免变形]
3. [产品区，例如实物更有质感，和价格之间留白]
4. [信息区，例如菜单更清晰，价格右对齐]
5. [整体，例如提高锐度、减少拥挤、适配电视远看]

不要新增无关元素，不要改变商品和价格，不要使用编号，不要出现平台UI。
```

## Template 3: Text/menu correction prompt
```text
请重点修复当前海报中的文字和价目表，整体风格、构图、主视觉保持不变。

【修复目标】
- 商品名准确
- 价格准确
- 单位准确
- 行距均匀
- 商品名左对齐，价格右对齐
- 分组标题清楚
- 不要出现编号或A/B/C标记
- 不要新增、删除或改写商品

【请准确呈现以下内容】
[粘贴最终商品清单]

其他元素保持不变，仅提升文字清晰度和排版规整度。
```

## Template 4: Final lock prompt
```text
这版作为最终方向锁定，不要重新设计，不要更换构图，不要改变文案，只做最后轻微优化。

仅优化：
- 整体锐度
- 文字清晰度
- 边缘细节
- 远距离可读性
- 少量留白和对齐

保持所有商品、价格、主标题、品牌元素和版式不变。不要添加新元素，不要删除已有重要信息。
```
