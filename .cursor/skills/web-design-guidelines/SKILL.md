# Web Design Guidelines

## 语义与结构

- 用合适标签表达结构（标题层级、列表、`main`/`nav`/`button`）；不要全 `div` + click。
- 表单：label 与控件关联；错误与 `aria-*` 在需要时使用（随栈而变）。

## 可访问性（最小集）

- 可键盘操作；可见焦点；不要只靠颜色传达状态。
- 图片有 `alt`；图标按钮有可读名称。
- 动态更新区域若影响读屏，按框架文档处理 live region。

## 性能

- 图片：合适格式与尺寸；懒加载非首屏；避免布局抖动（预留尺寸）。
- JS：避免阻塞首屏；拆分与按需；监控包体。
- 列表/表格大数据考虑虚拟化或分页。

## 安全与隐私（通用）

- 用户输入出现在 HTML 时防 XSS（使用框架默认转义，慎 `dangerouslySetInnerHTML` 等）。
- 敏感操作防 CSRF（按栈惯例）。

## 验收脑检

页面加载后：无控制台红色错误；关键路径可键盘完成；放大字号不灾难性破版。
