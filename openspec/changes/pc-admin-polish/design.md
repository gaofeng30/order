# 实现约束

保留原生 JavaScript 页面及共享 UI 结构，按需补足实例级关闭、请求代次、表单提交锁和页面离开确认。图片裁剪使用浏览器 Canvas，仅菜品图片裁成正方形，开屏 PNG 保持原比例与透明度。导入事务内记录真实结果 ID，结果读取沿用主账号鉴权并限制批次所有者；PostgreSQL 直连与 SharedPG 两条既有运行路径均实现。金额按用户确认的批量角精度计算，预览及提交共用结果。新的视觉效果须以本地预览/实际 UAT 观察为准。

用户追加修正：产品预览行保留可编辑字段与原始售价/餐段文本；页面保存编辑时重新生成 XLSX，复用服务端解析、校验和预览 token，不直接写菜品。可选 product_images 按行提交，复用已确认上传资源校验，图片对象键纳入预览幂等摘要与持久化计划，最终与菜品在同一事务内保存。员工导入不接收图片字段，既有脱敏边界不变。删除菜品在原事务内先锁定菜品并清理售罄记录，保留分类和订单快照。
