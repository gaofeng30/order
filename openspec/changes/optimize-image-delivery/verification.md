# 图片性能 UAT 验证（2026-10-14）

## 结论与修复
旧图和新上传图片统一通过固定对象版本的 COS 640px WebP 展示地址返回；不覆盖原件、不迁移商品数据。PC 裁剪改为最长边 640，不透明照片 JPEG .82，透明图 PNG。搜索/分类复用当前页面菜品读取，重新进入及写入后刷新。

## 实际测量与消融
同一 UAT 菜单、同一图片对象版本，只改变图片处理规则。9 张封面全部 HTTP 200：9,618,639 → 292,924 bytes，减少 96.95%。反馈中的乌冬面为 1,653,353 → 40,820 bytes。

256 KiB/s 限速，同图原件和派生图各 3 次下载，中位数 6.283s → 0.273s。本机不限速四并发的逐图中位数 0.404s / 0.414s；因此收益证据是传输量与受限带宽，不把本机结果外推为所有网络的同比加速。部署后 API 直接返回处理地址，9 图全部 200 WebP，单图本机 0.201–0.293s。

处理参数在签名中；篡改 640 为 320 返回 403。原对象版本、上传确认哈希与鉴权不变。
