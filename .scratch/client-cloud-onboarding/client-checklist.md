# Order：腾讯云服务器资源申请清单（甲方版）

更新：2026-09-22。本清单仅用于申请本项目的腾讯云资源，不是完整上线资料清单。**小程序和微信支付已由甲方办好，本轮不再索取相关资料或重复核验。**

## 第一步：甲方从零注册腾讯云账号

**当前情况：甲方还没有腾讯云账号。先注册并完成企业实名，再授权开发方；此时不用先购买服务器或充值。**

### 会前准备（只用于新云账号）

- 指定一名甲方长期账号保管人，并准备其可操作的微信、可接收短信的手机，以及甲方长期可控的联系邮箱。不要使用开发方的微信、手机号或邮箱作为主账号归属和找回联系方式。
- 准备本次云账号所属主体的准确名称、统一社会信用代码及营业执照电子材料，供实名页面按要求填写/上传；证件直接提交腾讯云，不发开发群。
- 若主体属于工商企业且采用法人微信扫码认证，提前约好法定代表人本人配合。账号保管人与法人可以不是同一个人；保管人注册登录，不代表其能代法人完成认证。

### 具体怎么操作

| 顺序 | 甲方操作 | 做到什么算完成 |
| --- | --- | --- |
| 1 | 打开[腾讯云中国站官网](https://cloud.tencent.com/)，点击“注册”，不要进入国际站 | 进入中国站注册流程；不需要新申请小程序或公众号 |
| 2 | 由甲方账号保管人按注册页面支持的方式完成注册；使用甲方控制的登录身份，短信/扫码验证由本人操作，阅读并确认平台协议 | 可以登录腾讯云控制台。不要把注册成功误认为已经企业实名 |
| 3 | 进入账号中心 → 账号信息/安全设置，核对账号 ID（UIN）、安全手机与邮箱；设置好可用的登录保护，密码及验证设备由甲方保管 | 甲方能独立登录、接收安全通知并管理账号；不把主账号密码交开发方 |
| 4 | 进入账号中心 → 实名认证，选择企业认证，按最新证件选择正确主体类型，填写主体信息并提交页面要求的材料；不要误选账号保管人的个人实名认证 | 主体信息与营业执照一致。只有实际页面要求的材料才提交 |
| 5 | 如为符合条件的工商企业，优先按官方推荐采用“企业法人微信扫码认证”，由法人本人扫描本次页面二维码完成；不适用或无法完成时，由开发方先核对平台允许的认证方式及所需配合，再安排甲方办理，不要求所有方式都做 | 实名认证页显示“已认证”且主体正确；不是仅“提交成功”或“审核中” |
| 6 | 把账号 ID（UIN）和企业实名通过状态告知开发方；随后按下表第 2 项开通开发人员子账号 | 开发方拿到的是账号标识和授权，不是主账号密码、验证码或证件原文 |

注册与实名是两个步骤。**因为本次是新建企业云账号，营业执照用于企业实名认证，不是让甲方重新办理小程序资料，也不是每买一种云资源都交一次。** 认证时间以实际结果为准，不承诺当天通过。[腾讯云注册与实名指引](https://cloud.tencent.com/document/product/378/52700)、[企业认证方式](https://cloud.tencent.com/document/product/378/10496)

## 甲方需配合的四件事总表

| 事项 | 甲方需要做什么 | 后台位置 / 完成标准 |
| --- | --- | --- |
| 1. 新建腾讯云账号 | 甲方目前没有账号，按上方六步注册中国站账号并完成企业实名 | 腾讯云 → 账号中心 → 实名认证。完成标准：正确主体已认证，主账号由甲方保管 |
| 2. 开发人员权限 | 给指定开发人员创建或复用独立 CAM 子用户，开放本项目所需的控制台权限；子用户使用开发人员自己的安全手机、邮箱及 MFA | 访问管理 CAM → 用户。开发方会前提供人员信息和精确权限清单；完成标准：开发人员能用自己的账号管理获授权的项目资源。不给全账号管理员权限，不交主账号密码或主账号 API 密钥 |
| 3. 首次服务授权 | CloudBase 首次开通时，配合确认服务条款及必要的云服务角色授权；已经开通且授权有效则跳过 | CloudBase 控制台 → 开通/服务授权。开发方说明每项用途；完成标准：所需服务可进入，必要角色授权已生效。服务角色与开发人员权限分开，不把角色宽权限直接授予人 |
| 4. 费用审批与付款 | 指定审批/付款人，确认开发方提供的具体资源订单、费用提醒接收人及是否自动续费，再付款 | 费用中心 → 订单/充值/续费。完成标准：批准的订单已支付或有明确付款安排，续费选择已记录。无需提前充值固定金额，不默认开启自动续费或授予开发方全局财务权限 |

企业实名通过后，后续资源购买复用该认证；不重复索取营业执照。认证所需的法人核验或对公验证以所选方式为准，不要求全部办理。

## 云资源与技术配置由开发方负责

| 项目 | 开发方负责的内容 |
| --- | --- |
| CloudBase 云托管 | 确认地域、套餐、实例规格和部署方式，整理订单并完成获授权的服务配置 |
| MySQL 数据库 | 选择独立 MySQL 资源，配置私网连接、受限数据库账号和备份；不让甲方决定端口或数据库密码 |
| 私有 COS | 配置本项目存储桶、私有访问及应用权限，不要求开放公有读 |
| 基础网络、日志和监控 | 核验服务与数据库同地域私网兼容、所需出网能力及费用，配置项目网络、安全规则、日志和告警 |

测试环境按已确认的最小规模准备。生产规格由开发方根据既定可用性要求整理成具体订单，甲方审批后再购买；本清单不新增预算或购买决定。**本方案不额外要求甲方购买 CVM 或 SSM。**

资源创建后，开发方按真实资源 ID 收敛权限，并提供资源清单与费用/到期提醒安排。技术参数和缺失权限由开发方提前梳理，不让甲方临场研究。

## 本轮不需要甲方准备

- 小程序、微信支付相关账号、资质、密钥、成员、模板或审核资料：已办好，不重复列入本次申请。
- 餐饮资质、商品图片价格、门店资料、业务验收人员：不是申请云资源的材料。
- 域名申请、域名实名、ICP备案、HTTPS 与域名接入：属于后续“对外访问准备”，不作为本轮采购云资源的甲方材料要求；不代表正式对外服务可以跳过这些条件。开发方下单前仍应检查所选资源是否满足后续备案及域名接入需要，避免买错后重购。

## 集中办理前后的安排

开发方会前准备：指定开发人员信息、项目权限清单、单一资源采购明细与费用、必须甲方操作的授权页面。甲方只需安排账号保管人和付款人配合；如尚未实名，再按选定认证方式安排相关人员。

已具备的账号、实名或授权直接复用。集中办理后仍可能遇到平台安全验证或补授权，不能承诺以后完全不需甲方配合；普通 CAM 子用户安全手机/邮箱的后续修改可能需要管理员处理。[CAM 官方说明](https://cloud.tencent.com/document/product/598/74572)

回执只记录：账号实名状态、子用户登录与项目权限验证结果、服务开通状态、订单/付款状态、续费选择及联系责任人。**不在群聊、普通文档或仓库记录密码、验证码、密钥或证件原文。** 当前未实际登录或配置甲方云账号，以上完成标准不等于已完成。
