# 点单小程序上线｜云资源与费用确认单

为保障已办理的小程序和微信支付服务上线，现就云资源、域名和费用安排征询贵单位意见。本单用于确认办理方案，具体采购以贵单位书面批准的订单为准；技术选型、配置和上线由开发方负责。

每项资源的用途、费用去向和采购条件详见[云资源明细与费用说明](https://my.feishu.cn/wiki/Zg3kw0ppriZQPlkeYNUc38PdnVe)。

| 资源事项 | 用途 | 参考费用与去向 |
| --- | --- | --- |
| 贵单位主体实名云账号 | 系统、数据及账单的长期归属；开发方获项目授权 | 开户不收费；云服务费用付腾讯云 |
| 正式运行环境 | 顾客点单、商家管理、订单及支付通知 | 标准版参考 199 元/月，付腾讯云 |
| 独立测试环境 | 上线前验证改动，不影响真实订单 | 个人版活动参考 19.9 元/月，付腾讯云；资格待核 |
| 域名与访问 | 固定、安全的服务地址；核定备案 | 优先复用；新购域名或其他必需资源另行报价 |
| 超额与附加项 | 套餐不足时补足必要能力 | 逐项列明用途、价格和收款方，获批后购买 |

基础套餐参考合计：**218.9 元/月**（正式环境 199 元、测试环境活动价 19.9 元）。这是公开标价估算，不是最终订单或费用上限；域名、超额用量、可能需要的备案资格资源及其他附加费用均未计入。下单前开发方提供实际价格、购买周期和收款平台，报贵单位书面批准。

## 建议的省时办理方式（待双方确认）

云账号、实名主体、域名和主账号由贵单位长期持有。开发方通过本项目授权账号完成配置、联调与排障，贵单位只需集中配合必要的实名、授权和平台验证。

经贵单位书面批准具体订单及首期、持续费用上限，并由双方财务确认开票和报销方式后，开发方可在批准额度内先行垫付。交付时移交资源、账单及运维资料；贵单位决定继续授权或收回开发方权限。

## 请贵单位确认以下 4 项

1. **云账号**：是否已有可用于本项目的腾讯云账号或云开发环境？如有，请告知账号保管人；如无，请指定保管人，以贵单位主体办理实名认证。
2. **域名**：现有可用于本项目的域名是什么？如没有，请回复“无”。
3. **费用**：首期拟购买时长与预算上限、每月持续费用上限各是多少？是否同意开发方在书面批准的订单内先垫付、后报销？请指定审批人和财务对接人。
4. **联系人**：请指定账号与费用通知、紧急故障和交付接收联系人，可由同一人兼任。

收到回复后，开发方会核对现有资产，给出一次性操作安排和实际订单；未经批准的额外费用不采购。
