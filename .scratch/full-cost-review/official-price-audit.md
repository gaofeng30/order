# Order 小程序全量官方成本审计表

核对日期：2026-09-02  
价格口径：微信开放文档、微信支付、工信部、腾讯云中国站公开页面。金额均为人民币含税展示价/公开单价；活动价、账号专享券、地域差价和登录后购物车价不冒充固定报价。  
规模口径：单门店、约 4,000–5,000 用户；一个根域名；中国大陆地域；首年；图片存储 10GB；每月 COS 外网下行 20–50GB；每名用户只成功绑定一次手机号。

## 一、先看结论

- **备案本身不是高价项**：普通 ICP 备案 0 元；微信小程序备案公开指引未列收费项；公安联网备案官方流程未列收费项。
- 当前可公开核实的最低固定基础是：`.cn` 域名 33 元/首年 + CVM 531 元/年。数据库若改用官方公开的轻量数据库 1核1GB/20GB，则是 420 元/年；但这不是现有技术文档要求的 TencentDB MySQL 双节点形态，需要架构确认后才能替换。
- 以“单环境先 UAT、验收后原环境转生产”的低成本模型估算：本机日志方案首年 **1,202.28–1,412.28 元**；启用低量 CLS 后首年 **1,246.02–1,456.02 元**；两者均另加微信认证后台订单价和微信支付交易手续费。该数使用轻量数据库，不是当前严格架构报价。
- 如果按 TencentDB MySQL 8.0、2核4GB、100GB 的当前 480 元/月配置建单，首年为 **6,542.28–6,752.28 元**；启用同口径低量 CLS 后为 **6,586.02–6,796.02 元**。最终仍以登录后的腾讯云购物车为准。
- 当前技术文档的“CAT 每分钟一次公网拨测”很贵：单个 IDC 节点约 **1,296 元/月、15,552 元/年**（按 30 天计费月×12）。它不适合首发 MVP，除非明确接受这笔监控费。
