# 菜品物料打包说明（p001–p007）

本压缩包整理了点餐小程序中 **p001 至 p007** 七个菜品的图片素材与文字物料信息，便于设计、运营或对接方离线查看。

整理日期：2026-06-10
数据来源：`miniprogram/assets/dishes/`（图片）、`miniprogram/mock/data.js`（文字信息）

## 目录结构

```
dishes-package/
├── README.md          ← 本说明文件
├── dishes-info.md     ← 七个菜品的物料信息与介绍（价格、简介、规格、过敏原等）
└── images/            ← 菜品图片素材
    ├── p001.png  p001.svg
    ├── p002.png  p002.svg
    ├── p003.png  p003.svg
    ├── p004.png  p004.svg
    ├── p005.png  p005.svg
    ├── p006.png  p006.svg
    └── p007.png  p007.svg
```

## 内容说明

- **images/*.png**：菜品成品图（高清位图，约 1.6–1.8 MB / 张），小程序中实际展示用图。
- **images/*.svg**：对应的矢量占位图素材。
- **dishes-info.md**：逐个菜品列出的文字物料，包括：名称、所属分类、价格、简介（intro）、详细介绍（desc）、月销量、库存、标签、上架状态、规格、过敏原信息。
