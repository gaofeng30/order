## 评审重点

- 用户端点单、购物车、确认订单、取餐码链路是否顺畅。
- 商户端商品、分类、订单、核销和看板能力是否覆盖日常运营。
- 外卖、餐段、员工身份、退款、门店/档口、后台角色等待确认事项是否需要进入首期范围。
- 当前商务蓝 + 语义绿色的视觉方向是否适合政府/企业食堂场景。
- 价目表、供应明细和海报内容是否与小程序商品、档口、套餐配置保持一致。
