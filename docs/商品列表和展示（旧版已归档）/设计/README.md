# Design And Poster Assets

This folder is the single home for poster deliverables, poster generation work, and visual references.

## Structure

- `color-proportion.md`: UI color proportion guideline.
- `20260516-poster-final-deliverables/`: current selected 8 poster images, matching prompts, and manifest.
- `20260517-poster-tv5-tea-lab-redesign/`: TV5 tea lab redesign candidates, prompts, and scripts.
- `20260517-poster-tv7-summer-redesign/`: TV7 summer mountain/wave redesign work, prompts, and scripts.
- `20260515-poster-initial-generation/`: original poster generation batch, history, prompts, and zip archive.
- `20260515-poster-source-assets/`: poster source price tables and reference image.
- `20260515-poster-references/`: first design reference poster set.
- `20260515-poster-v2-references/`: second design reference poster set and zip archive.
- `20260515-source-references/`: raw visual reference images unrelated to the generated poster batch.
- `poster-scripts/`: reusable poster conversion and generation scripts.
- `20260517-poster-unsorted-notes/` and `20260517-unsorted-notes/`: temporary notes or files that need later classification.
