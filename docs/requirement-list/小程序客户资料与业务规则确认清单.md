# 小程序客户资料与业务规则确认清单



## 一、文档用途

这份清单用于准备微信点单小程序的注册、认证、微信支付接入、上线审核、权限配置和正式开发前的业务规则确认。



**请客户按表格逐项填写、准备材料或确认业务规则**。小程序账号、微信支付商户号、收款账户、退款责任均建议由客户自己的主体持有，开发方作为项目成员协助开发、配置、提审、上线和运维支持。

## 三、必填口径说明

|口径|含义|
|---|---|
|官方必填|注册小程序、主体认证、微信支付申请或微信支付接口中通常必须提供的内容|
|按类目必填|不是所有小程序都必填，但餐饮或食品相关服务类目通常需要提供的内容|
|上线必填|注册阶段不一定马上填写，但正式提交审核和上线前必须准备的内容|

|建议准备|不一定马上用到，但提前准备能减少审核、设计或配置返工|
|按需确认|取决于客户现场规则或是否进入第一期范围|
