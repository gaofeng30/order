# 腾讯云生产资源开通与运维指南

> 适用范围：政府/企业食堂在线点单系统一期，500 人以内、短时集中点单。
> 本指南是客户采购与责任视图；组件、数据流和运行边界以 [`在线点单系统技术文档`](../product/online-ordering-system-technical.md) 的生产架构基线为准。
> 甲方持有企业云账号、域名、微信身份、支付商户号、资产与费用责任；乙方在获授权范围内完成配置、部署协助、联调与技术运维。实际操作以当前用户授权和[唯一生产 Runbook](../../deploy/runbooks/order-production-release.md)为准；本文不提供第二套执行步骤。

## 1. 已确认生产资源

复用已存在的独立 Prod CloudBase 环境、CloudRun Go API、Shared PostgreSQL 和同地域私有 COS，正式 HTTPS 网关承载 API 与 `/pc/` 静态入口。材料通过受保护运行配置注入，业务数据库使用普通身份，COS 使用限定桶与前缀的 STS。具体资源标识、版本与回执集中在[生产 Runbook](../../deploy/runbooks/order-production-release.md)。

旧 CVM、CDB MySQL、Nginx、systemd 和 SSM 采购/安装步骤已撤销，不再作为生产路线。没有新增 Redis、MQ、跨地域灾备或 7×24 人工值守要求。

## 2. 外部信息与责任

甲方确认云资产归属、地域、域名、微信 AppID、商户归属、预算和必要授权；乙方在授权范围内核验环境、普通数据库身份、桶、域名/TLS 和运行材料。资源标识及当前状态写入 Runbook；凭据、私钥、密码、完整证书和可重放报文不得写入文档。既有资源不足的结论须有实测依据，不能沿用旧采购占位符要求另购实例。

## 3. 平台与运行边界

### 3.1 企业账号、域名和合规

1. 甲方使用企业主体注册腾讯云账号并完成企业实名认证；主账号不得交付给乙方。
2. 甲方持有域名与备案主体；操作见 [`域名操作指南`](./域名操作指南.md) 与 [`ICP备案操作指南`](./ICP备案操作指南.md)。
3. 甲方开通最小权限 CAM 子账号或授权角色；乙方不要求常驻主账号权限。
4. UAT 与生产的环境、数据、访问身份、桶、域名及回调配置隔离；沿用已确认的小程序 AppID 和商户归属，不能自行要求另建账号。

境内公网服务的域名、TLS、网站 ICP 和小程序备案分别核验，网站 ICP 不等于小程序备案。实际状态与续期责任记录在 Runbook。

### 3.2 CloudRun 与 Shared PG

复用已确认的 CloudRun + Shared PG 路线。数据库关系迁移、函数安装、定义及 ACL/RLS 核对、材料注入与部署均只按 Runbook 执行，已成功执行的迁移不重复。管理安装成功不能替代普通运行身份验证。

PRD 要求核心数据备份与恢复演练方案，必须核实目标 Shared PG 的实际能力并保留恢复实证；不要求固定的 14 天/7 天保留、PITR、季度频次或 RPO/RTO 数字，不为这些自加指标购买资源。

### 3.3 私有 COS

保留私有访问、服务端生成对象路径、短期上传/读取授权，以及上传后的类型、大小、摘要校验。Prod 本次适配采用唯一对象路径与禁止覆盖，删除原生版本号、历史版本保留及图片误删恢复要求；该适配尚未发布，必须按 Runbook 的候选版本验证后生效。历史 UAT 已启用配置及实际回执不改写。

缩略图及图片加载效果按实际体积和耗时验证；任何新增计费先确认，不能以此文自动授权开通。

### 3.4 运行材料与访问权限

普通数据库身份及环境绑定、受限 COS STS、微信支付/退款材料和通知 formal 配置通过受保护运行配置注入。生产材料不复制自 UAT，秘密不进入客户端、源码、镜像和日志；缺少必要材料不能降级为假业务成功。

### 3.5 日志与异常检查

保留脱敏结构日志、关键操作审计和资金/通知异常查询。日志不得包含请求正文、Authorization、Cookie、个人信息、回调原文或凭据。不强制购买 CLS/CAT 或日志保留套餐，不追加无 PRD 依据的完整固定监控阈值；费用告警与证书现状按 Runbook 只读核验，新增费用先确认。

## 4. 环境隔离与部署

单个运行进程绑定唯一环境；UAT 与 Prod 的 CloudBase 环境、数据库和身份、私有 COS 及访问权限、域名和回调配置分别核验。生产不得复制 UAT 示例数据或凭据，生产数据不得原样进入开发环境。

安装、构建、部署、静态资源先于 HTML 发布、状态读回、业务验收、失败处理与回滚的唯一执行入口为[生产 Runbook](../../deploy/runbooks/order-production-release.md)。设计文档、HTTP 200 或代码提交不代表完整上线验收。

## 5. 容量验收

按 PRD §9.2 的 5–10 分钟集中 100–300 单、日 500–1000 单验证，核心交易不得被统计阻塞。保留幂等、权限和资金结果验证，不追加 200 并发、300 商品、固定 p95 或已废止库存门禁。记录实际规格与结果；不足时先诊断，涉及升级费用再确认。

## 6. 成本与采购边界

复用现有套餐和资源；资源点、存储、请求、图片处理、流量等以目标环境实时计价与实际账单为准，本文不承诺价格或免费额度。新增资源、升级、充值、费用开关或可能扩大费用的操作先向甲方核对。不能因本文原有的固定备份、监控或容量指标自动产生采购需求。

## 7. 安全交接清单

甲方只提供资源标识与最小授权，不在聊天、邮件、文档、代码或前端配置中传递敏感正文。乙方需要的最小信息为第二节所列资源信息与任务范围内最小权限。

以下内容不得交付或入库：主账号密码、运行环境登录凭据正文、数据库密码、长期访问 key、微信商户私钥、APIv3 key、证书正文、回调报文、个人信息。排障授权必须限时、最小权限并保留审计；收款主体和经营责任始终属于甲方。

微信支付平台操作见 [`微信支付操作指南`](./微信支付操作指南.md)。回调必须先验签、解密和持久化去重再应答成功。通知意图与业务事实原子提交，首次及时发送；真实异常持久登记后失败间隔 30 分钟重试，成功停止。重启、多实例接管及未知资金结果收敛须有实际验证，不以内存 timer 代替持久恢复。
