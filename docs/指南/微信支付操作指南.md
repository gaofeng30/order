# 微信支付（小程序支付）开通操作指南

> 适用范围：本指南面向甲方对接人，用于「在线点单系统」第一期开通**微信小程序在线支付**所需的商户号申请与配置。
> 读者定位：有一定基础的对接人。技术接入（带 🔧 标记）由乙方负责，甲方只需配合提供资料与点击确认。
> 截图说明：本指南每一步均附**微信支付官方文档截图链接**，点击即可看到对应页面的官方实时界面（界面会随官方版本更新，以官方页面为准）。
>
> ⭐ 前置条件：开通微信支付须先有**已认证的微信小程序**，请先完成 [`微信小程序注册与企业认证指南.md`](./微信小程序注册与企业认证指南.md) 并拿到 AppID。

## 一、开始之前

### 1.1 你需要先准备好这些

| 资料 | 用途 | 备注 |
|------|------|------|
| 营业执照（彩色扫描件/照片） | 主体认证、支付进件、餐饮类目核验 | 名称、统一社会信用代码、经营范围、有效期需清晰可见 |
| 法定代表人身份证（正反面） | 进件、人脸/身份核验 | 法人需配合扫码、人脸、短信核验 |
| 对公银行账户 | 结算、账户验证 | 开户名须与营业执照主体一致 |
| 企业联系人信息 | 审核、回访 | 姓名、手机号、邮箱，手机号保持畅通 |
| 客服电话 | 商户展示、售后 | 可公开展示且能接通 |
| 已认证的微信小程序 | 绑定支付能力 | 小程序须为**企业主体**且已通过认证 |

> 💡 账号归属提醒（见合同第 90 行）：小程序账号、微信支付商户号、对公账户均应归**甲方企业主体**所有，乙方仅作技术协助，不长期代持。

### 1.2 整体流程总览

```
① 注册/登录商户平台
        ↓
② 提交申请资料（商户信息 + 经营信息 + 结算账户）
        ↓
③ 账户验证（向对公账户打款验证）
        ↓
④ 微信支付审核（1–2 个工作日）→ 在线签署协议
        ↓
⑤ 绑定小程序 APPID（小程序方确认授权）
        ↓
⑥ 🔧 技术接入配置（API 密钥 / APIv3 密钥 / 商户 API 证书）—— 乙方负责
        ↓
   ✅ 完成，可在小程序内收款
```

⏱️ 全程预计 **3–7 个工作日**（主要时间在官方审核与账户验证打款到账）。

## 二、详细操作步骤

### 第①步：注册 / 登录微信支付商户平台

1. 打开商户平台官网：**https://pay.weixin.qq.com/**
2. 已有商户号 → 直接用「商户号 + 登录密码」登录。
3. 没有商户号 → 点击右上角「**接入微信支付**」/「免费注册」，按场景「**我有小程序**」开始申请。

> 📷 官方截图参考（接入场景选择页，选「我有小程序」）：
> https://pay.weixin.qq.com/static/applyment_guide/applyment_index.shtml

---

### 第②步：提交申请资料

按官方「我有小程序」指引，在线填写并上传：

1. **商户信息**：营业执照、法定代表人身份证。
2. **经营信息**：经营类目选择**餐饮相关**类目，填写门店/经营场景、客服电话。
3. **结算账户**：填写对公银行账户（开户名、开户行、银行账号、开户行所在省市）。

> ⚠️ 类目要选对：点单系统属餐饮场景，类目错误会被驳回或影响费率。
> 📷 官方截图参考（「我有小程序」完整申请流程与资料清单）：
> https://pay.weixin.qq.com/static/applyment_guide/applyment_detail_miniapp.shtml

---

### 第③步：账户验证

提交结算账户后，微信支付会向你填写的**对公账户打入一笔小额随机金额**，你需要：

1. 查询对公账户到账的随机金额（通常几分钱到几元）。
2. 回到商户平台，在账户验证页**填入收到的金额**完成验证。

> 💡 到账时间取决于银行，通常当天或次日。验证通过后账户即被确认。

---

### 第④步：审核与签署协议

1. 微信支付团队在 **1–2 个工作日**内完成审核。
2. 审核通过后，登录商户平台**在线签署**《微信支付服务协议》。
3. 签约完成后，商户号正式生效。

> 💡 审核中如收到补充资料通知，按提示及时补交，避免延期（合同第 172 行：因资料不齐、审核延迟等非乙方原因造成的延期不视为乙方违约）。

---

### 第⑤步：绑定小程序 APPID

这一步把「商户号」和「小程序」关联起来，是小程序内能调起支付的前提。

**A. 在商户平台发起绑定**

1. 登录商户平台。
2. 进入：**产品中心 → APPID 授权管理 → ＋关联 AppID → 新增授权**。
3. 填写小程序的 **AppID**。
4. 勾选《微信支付商户号与 APPID 授权协议》→ 点击「**提交**」。

> 📷 官方截图参考（绑定 APPID 操作）：
> https://pay.weixin.qq.com/doc/v3/merchant/4013287504

**B. 在小程序后台确认授权**

由小程序账号持有人登录**微信公众平台**（https://mp.weixin.qq.com/）确认：

- PC 端：点击「**微信支付 → 商户号管理**」，在「待关联商户号」中**确认授权**。
- 移动端：通过「公众平台安全助手」下发的模板消息确认。

> ⚠️ 若小程序是委托第三方创建的，需先设置邮箱密码后登录 PC 端确认授权。

---

### 第⑥步：🔧 技术接入配置（乙方负责）

以下由乙方在你授权后操作，**甲方只需用超级管理员账号配合输入操作密码/短信验证码**。列出供你了解与配合：

1. **设置 APIv3 密钥**
   - 路径：**账户中心 → 账户设置 → API 安全 → 设置 APIv3 密钥**。
   - 输入 32 位密钥（数字 + 大小写字母）→ 操作密码 + 短信验证 → 完成。
   - ⚠️ 设置后**无法查看，只能重置**，请乙方妥善保存。
   - 📷 官方说明：https://pay.weixin.qq.com/docs/merchant/development/interface-rules/apiv3key.html

2. **设置 API 密钥（APIv2，按需）**
   - 路径：**账户中心 → 账户设置 → API 安全 → 设置 API 密钥**。

3. **申请商户 API 证书**
   - 路径：**账户中心 → 账户设置 → API 安全 → 商户 API 证书 → 申请证书**。
   - ⚠️ 证书私钥只能通过证书工具导出，**丢失无法找回**，只能作废重申。
   - 📷 官方说明：https://pay.weixin.qq.com/doc/v3/merchant/4012072428

4. **配置支付回调地址**（由乙方在后端配置，见合同第 86 行）。

## 三、需要交给乙方的参数清单

技术接入时，乙方需要以下 5 项参数（甲方在商户平台获取或授权乙方配置）：

| 参数 | 说明 | 来源 |
|------|------|------|
| 小程序 AppID | 小程序唯一标识 | 微信公众平台 |
| 商户号 MchID | 微信支付商户号 | 商户平台 |
| APIv3 密钥 | 回调/平台证书解密 | 第⑥步设置 |
| 商户证书序列号 | 标识商户 API 证书 | 账户中心 → API 安全 → 管理证书 |
| 商户 API 私钥（apiclient_key.pem） | 接口签名 | 申请证书时导出 |

> 🔒 安全提醒：APIv3 密钥、API 私钥属敏感凭据，请通过安全渠道交付乙方，不要发普通群聊/邮件明文。

## 五、常见问题

- **Q：审核要多久？** A：资料齐全一般 1–2 个工作日，加上账户验证打款到账，整体 3–7 个工作日。
- **Q：一个商户号能绑多个小程序吗？** A：可以，商户号与 AppID 是多对多关系，在「APPID 授权管理」中可关联多个。
- **Q：APIv3 密钥忘了能查吗？** A：不能查看，只能重置；重置后需乙方同步更新后端配置。
- **Q：类目填错怎么办？** A：可在商户平台申请变更经营类目，但可能需重新审核，建议一开始就选餐饮类目。
