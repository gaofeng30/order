# 腾讯云（云服务器 / 数据库 / 对象存储）开通操作指南

> 适用范围：本指南面向甲方对接人，用于「在线点单系统」第一期开通后端运行所需的**腾讯云**资源：云服务器（CVM）、云数据库（MySQL / TDSQL-C）、对象存储（COS，用于存菜品图片）。
> 读者定位：有一定基础的对接人。带 🔧 标记的配置由乙方负责，甲方主要负责**注册账号、实名认证、购买付费**。
> 截图说明：每一步均附**腾讯云官方文档链接**，点击即可看到对应操作页面的官方实时界面（界面会随官方版本更新，以官方页面为准）。
>
> 🔗 配套文档：**域名注册**见 [`域名操作指南.md`](./域名操作指南.md)；**ICP 备案**为独立合规流程，见 [`ICP备案操作指南.md`](./ICP备案操作指南.md)；微信支付见 [`微信支付操作指南.md`](./微信支付操作指南.md)。

## 一、开始之前

### 1.1 你需要先准备好这些

| 资料 | 用途 |
|------|------|
| 营业执照 | 企业实名认证 |
| 法定代表人身份证 | 实名认证 |
| 企业对公账户或法人微信/支付方式 | 购买云资源付费 |
| 一个域名 | 小程序后端服务、HTTPS（建议企业主体购买） |

> 💡 账号归属提醒（合同第 90 行）：企业云账号、域名均应归**甲方企业主体**所有，乙方仅作技术协助。如需委托乙方代购代办，须双方另行书面确认。
> 🔗 ICP 备案另需主体/网站负责人信息等资料，见 [`ICP备案操作指南.md`](./ICP备案操作指南.md)。

### 1.2 各资源的角色

```
云服务器 CVM      → 跑后端程序（订单、支付、核销逻辑）
云数据库 MySQL    → 存订单、商品、用户等核心数据
对象存储 COS      → 存菜品图片、静态资源（配 CDN 加速）
域名             → 小程序后端访问与 HTTPS（备案见独立文档）
```

### 1.3 整体流程总览

```
① 注册腾讯云账号 + 企业实名认证
        ↓
② 购买云服务器 CVM
        ↓
③ 购买云数据库（MySQL / TDSQL-C）
        ↓
④ 开通对象存储 COS + 创建存储桶
        ↓
⑤ 购买/转入域名
        ↓
⑥ 🔧 环境配置与部署 —— 乙方负责
        ↓
   ✅ 后端上线可用
```

⏱️ 云资源购买本身很快（当天可完成）。
> ⚠️ 后端正式对外提供服务前还需完成 **ICP 备案**（独立流程，一般 7–20 个工作日，整体上线瓶颈），请尽早启动，详见 [`ICP备案操作指南.md`](./ICP备案操作指南.md)。

## 二、详细操作步骤

### 第①步：注册账号 + 企业实名认证

1. 打开腾讯云官网并注册：**https://cloud.tencent.com/**
2. 登录控制台：**https://console.cloud.tencent.com/**
3. 完成**企业实名认证**（用营业执照，认证主体须与后续备案、发票主体一致）。

> ⚠️ 务必用**企业主体**认证，不要用个人，否则后续备案、发票、资产归属都会有问题。

---

### 第②步：购买云服务器 CVM

1. 进入购买页：**https://buy.cloud.tencent.com/cvm**（或控制台 → 云服务器 → 新建）。
2. 按顺序选择配置：
   - **计费模式**：长期使用选「包年包月」；短期测试可「按量计费」。
   - **地域 / 可用区**：选靠近目标用户的地域（如华南-广州）。⚠️ 备案与服务器地域相关，建议境内地域。
   - **实例机型**：第一期点单系统并发不高，入门机型（如 2 核 4G）通常够用。
   - **镜像**：选操作系统（如 Linux / Ubuntu，由乙方确认）。
   - **系统盘 / 公网带宽**：按需，带宽可后调。
   - **安全组**：放通必要端口（由乙方配置）。
   - **登录方式**：设置密码或 SSH 密钥（交给乙方）。
3. 核对费用 → 同意协议 → **立即购买**。

> 📷 官方步骤：通过购买页创建实例 https://cloud.tencent.com/document/product/213/4855
> 📷 新手指引：https://cloud.tencent.com/document/product/213/44971

---

### 第③步：购买云数据库（MySQL / TDSQL-C）

1. 进入数据库购买页（控制台 → 数据库 → 选 MySQL 或 TDSQL-C MySQL 版）。
2. 配置：地域/可用区（**与 CVM 同地域同可用区**，降低延迟）、规格、存储空间、版本。
3. 设置基础信息与高级配置 → 选购买时长 → 确认费用 → **立即购买**。

> 💡 具体用 MySQL 还是 TDSQL-C，由乙方根据架构确定后告知你在购买页选哪个。
> 📷 官方步骤：创建 TDSQL-C MySQL 集群 https://cloud.tencent.com/document/product/1003/63010

---

### 第④步：开通对象存储 COS 并创建存储桶

用于存放**菜品图片**等静态资源。新认证账号即可直接使用。

1. 进入 COS 控制台 → **存储桶列表 → 创建存储桶**。
2. 填写配置：
   - **名称**：自定义（仅小写字母、数字、短横线）。
   - **地域**：选与业务一致的地域，⚠️ **创建后不可更改**。
   - **数据冗余**：单可用区 / 多可用区（容灾）。
   - **访问权限**：菜品图片需公开展示可选「公有读私有写」（由乙方确认）。
3. 确认 → **创建**。

> 📷 官方步骤：创建存储桶 https://cloud.tencent.com/document/product/436/14106
> 📷 选购页：https://buy.cloud.tencent.com/cos

---

### 第⑤步：购买 / 转入域名

域名注册与实名为**独立流程**，详见 [`域名操作指南.md`](./域名操作指南.md)。要点：以**企业主体**注册（建议 `.com`/`.cn`），并完成域名实名（主体须与备案、营业执照一致）。

---

### 第⑥步：🔧 环境配置与部署（乙方负责）

以下由乙方完成，甲方配合提供账号权限或子账号即可：

- 服务器环境搭建、后端程序部署、安全组与端口配置。
- 数据库初始化、连接配置。
- COS 密钥（SecretId / SecretKey）配置、图片上传/读取接入。
- 域名解析、HTTPS 证书、小程序后端合法域名配置。

## 五、常见问题

- **Q：CVM、数据库、COS 地域要一致吗？** A：CVM 与数据库建议**同地域同可用区**以降低延迟；COS 选同地域即可。
- **Q：用个人账号买可以吗？** A：不建议。应使用企业主体，保证认证、备案、发票、资产归属一致。
- **Q：买完云服务器就能上线了吗？** A：还不行。境内服务器对外提供服务须先完成 ICP 备案，见 [`ICP备案操作指南.md`](./ICP备案操作指南.md)。
