# 微信点单小程序客户资料准备清单

## 一、文档用途

这份清单用于准备微信点单小程序的注册、认证、微信支付接入、上线审核和正式开发前的业务确认。

请客户按表格逐项填写或准备材料。小程序账号、微信支付商户号、收款账户、退款责任均建议由客户自己的主体持有，开发方只作为项目成员协助开发、配置和上线。

## 二、填写说明

| 项目 | 说明 |
| --- | --- |
| 适用项目 | 微信点单小程序 |
| 客户主体 | 个体工商户 |
| 当前状态 | 客户暂无已认证小程序账号，暂无微信支付商户号，需要先注册并认证 |
| 已确认事项 | 客户使用自己的主体注册小程序，并使用自己的微信支付商户号收款 |
| 开发方职责 | 协助准备资料、开发小程序、配置测试环境、协助提交体验版和上线审核 |
| 客户职责 | 持有小程序账号、完成主体认证、申请微信支付、确认业务规则、承担收款与退款责任 |

## 三、必填口径说明

| 口径 | 含义 |
| --- | --- |
| 官方必填 | 注册小程序、主体认证、微信支付申请或微信支付接口中通常必须提供的内容 |
| 按类目必填 | 不是所有小程序都必填，但餐饮或食品相关服务类目通常需要提供的内容 |
| 上线必填 | 注册阶段不一定马上填写，但正式提交审核和上线前必须准备的内容 |
| 项目必填 | 不是平台注册必填项，但本点单系统要上线或开发必须确认的内容 |
| 建议准备 | 不一定马上用到，但提前准备能减少审核、设计或配置返工 |
| 按需确认 | 取决于客户现场规则或是否进入第一期范围 |
