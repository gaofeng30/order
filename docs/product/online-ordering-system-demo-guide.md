# 在线点单小程序 Demo 说明

这套 Demo 主要用于展示“用户线上点单、到店自提、商户后台管理”的完整流程。当前版本已经可以连贯演示从用户选餐到商户核销的主链路。

## 一、用户端功能

用户端面向单位员工、访客等点餐人群，入口包括：首页、点单、订单和我的。

### 1. 首页

- 展示食堂名称、营业状态、营业时间和取餐地点。
- 展示门店公告，方便商户发布高峰提醒、临时通知等信息。
- 展示今日推荐菜品，用户可直接查看详情或加入购物车。
- 预留外卖配送入口，当前仅作为后续功能展示，不开放实际配送。

### 2. 点单

- 按“今日套餐、热销菜品、轻食低脂、汤饮甜品”等分类浏览菜品。
- 菜品展示名称、图片、价格、简介、销量、库存和标签。
- 支持直接加购、减少数量。
- 售罄菜品会保留展示，但不可购买。
- 下架菜品会显示不可购买状态，便于演示商户上下架管理效果。

### 3. 菜品详情

- 展示菜品图片、价格、介绍、规格、库存和过敏原提示。
- 支持选择购买数量并加入购物车。
- 对暂不可购买的菜品，会提示当前不可购买。

### 4. 购物车

- 展示已选菜品、数量和总价。
- 支持调整数量、清空购物车。
- 购物车为空时会提示用户先选择菜品。
- 可从购物车进入确认订单页。

### 5. 确认订单

- 展示商品明细、合计金额、取餐地点和预计取餐时间。
- 支持填写联系人、手机号和备注。
- 支持选择口味要求，如少辣、少盐、不要香菜等。
- 当前为模拟提交流程，可演示“确认支付/提交订单”后的效果。

### 6. 下单结果与取餐凭证

- 下单成功后展示订单状态、取餐号和订单信息。
- 订单详情页展示取餐号、二维码样式凭证、取餐地点、取餐时间、菜品明细和备注。
- 支持复制取餐号，方便用户到窗口核销。

### 7. 我的订单

- 支持按全部、待取餐、已完成、已取消查看订单。
- 用户可以进入订单详情查看取餐信息和历史订单。
- 用户下单后，订单会自动出现在订单列表中。

### 8. 我的

- 展示用户姓名、身份、手机号和单位信息。
- 提供订单入口。
- 外卖入口当前显示“暂未开放”，用于说明后续扩展方向。

## 二、商户端功能

商户端用于展示餐饮企业日常运营管理能力，入口包括数据看板、订单管理、商品管理、分类管理、核销和营业设置。

### 1. 商户入口

- Demo 启动页可选择进入用户端或商户端。
- 商户端入口提供看板、订单和核销等常用操作。

### 2. 数据看板

- 展示今日营收、订单数、访问量、点击量。
- 展示单品销量排行，方便商户查看热销菜品。
- 展示最近订单，便于快速跟进履约情况。
- 用户端新增订单后，看板中的订单数和营收会同步变化。

### 3. 订单管理

- 展示订单号、取餐号、用户信息、金额、状态和下单时间。
- 支持进入订单详情查看菜品明细、联系人、手机号、备注和取餐信息。
- 支持从订单列表直接进入核销。
- 用户刚提交的新订单会出现在商户订单列表中。

### 4. 订单详情

- 展示订单状态、取餐号、订单金额和商品明细。
- 展示用户备注和口味要求，方便窗口备餐时核对。
- 可从订单详情进入核销页面。

### 5. 核销

- 支持按取餐号核销订单。
- 支持从订单列表或订单详情带入对应订单核销。
- 核销成功后，订单状态会变为“已完成”。
- 用户端订单状态也会同步更新，方便演示完整闭环。

### 6. 商品管理

- 展示所有菜品及其分类、价格、库存和状态。
- 支持上架、下架切换。
- 支持进入商品编辑页修改商品信息。
- 可查看售罄、下架等状态对用户端购买行为的影响。

### 7. 商品编辑

- 支持修改商品名称、价格、库存、简介、描述等信息。
- 保存后回到商品列表，演示商户自主维护菜品的能力。

### 8. 分类管理

- 展示当前菜品分类。
- 支持启用、停用分类。
- 适合演示每日菜单、餐段菜单或不同档口菜单的管理思路。

### 9. 营业设置

- 支持设置营业状态。
- 支持维护营业时间、截单时间、取餐地点和公告。
- 保存后，用户端首页会使用最新营业信息。

## 三、当前 Demo 边界

当前版本用于演示业务流程和页面效果，暂未接入真实生产系统。

- 支付为模拟流程，未接入微信支付。
- 数据为本地演示数据，未接入真实后台数据库。
- 用户身份为演示身份，未接入真实微信登录或手机号授权。
- 二维码为页面演示样式，暂未接入真实扫码识别。
- 外卖配送仅预留入口，暂未开放实际配送流程。
- 正式上线前仍需补齐后端服务、支付回调、权限管理、数据存储、退款规则和小程序审核配置。
